# Budget Variance Analysis

Use this skill when the user needs to explain budget variance by driver and recommend accountable forecast or spending actions.

## Inputs

- Budget and actuals.
- Account definitions.
- Operational drivers and forecast.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Reconcile periods and accounting scope.
2. Separate volume, price, timing, and mix effects.
3. Identify recurring versus one-time variance.
4. Connect actions to forecast impact.

## Deliverables

- Variance bridge.
- Driver analysis.
- Updated outlook.
- Action plan.

## Guardrails

- Do not provide accounting conclusions without source records.
