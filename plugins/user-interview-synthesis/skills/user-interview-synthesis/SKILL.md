# User Interview Synthesis

Use this skill when the user needs to synthesize interviews into evidence-backed needs, patterns, contradictions, and research implications.

## Inputs

- Interview notes or transcripts.
- Research questions.
- Participant attributes.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Code evidence by behavior and need.
2. Compare segments and counterexamples.
3. Separate participant statements from interpretation.
4. Map findings to product implications.

## Deliverables

- Theme map.
- Evidence table.
- Personas or jobs when supported.
- Research gaps.

## Guardrails

- Protect participant identity.
- Do not generalize beyond the sample.
