# SEO Content Brief

Use this skill when the user needs to create a search-focused content brief grounded in user intent, credible sources, and differentiated value.

## Inputs

- Target topic and audience.
- Business objective.
- Keyword or search evidence.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Map primary and secondary search intent.
2. Review competing result patterns.
3. Define a differentiated angle and evidence needs.
4. Design outline, internal links, and conversion path.

## Deliverables

- Search-intent map.
- Content outline.
- Evidence checklist.
- Metadata suggestions.

## Guardrails

- Avoid keyword stuffing.
- Do not fabricate search volume.
