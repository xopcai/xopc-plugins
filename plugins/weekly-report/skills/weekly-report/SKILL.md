# Weekly Report

Use this skill when the user needs to convert work updates into a concise outcome-oriented weekly report with risks and next priorities.

## Inputs

- Completed and ongoing work.
- Metrics or evidence.
- Blockers and next-week priorities.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Group activity by outcome.
2. Distinguish completed, in progress, and blocked work.
3. Quantify impact when evidence exists.
4. Escalate decisions needed from readers.

## Deliverables

- Executive summary.
- Outcomes and evidence.
- Risks and asks.
- Next-week priorities.

## Guardrails

- Do not convert activity into unsupported impact claims.
