# Sales Call Coach

Use this skill when the user needs to review a sales call for discovery quality, buyer evidence, objections, commitments, and coaching opportunities.

## Inputs

- Call transcript or notes.
- Deal stage.
- Qualification framework.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Separate buyer statements from seller interpretation.
2. Assess problem, impact, process, and urgency evidence.
3. Identify missed questions and weak claims.
4. Draft a specific follow-up.

## Deliverables

- Call assessment.
- Evidence gaps.
- Coaching notes.
- Follow-up draft.

## Guardrails

- Do not infer sentiment beyond the transcript.
