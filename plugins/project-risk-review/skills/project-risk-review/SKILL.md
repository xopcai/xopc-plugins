# Project Risk Review

Use this skill when the user needs to identify project risks, quantify exposure, and turn mitigations into owned actions and triggers.

## Inputs

- Project plan.
- Dependencies and assumptions.
- Status and constraints.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Identify risks across scope, schedule, people, technology, and vendors.
2. Estimate likelihood and impact consistently.
3. Define prevention, contingency, and trigger.
4. Assign owners and review cadence.

## Deliverables

- Risk register.
- Heat map.
- Mitigation plan.
- Escalation agenda.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
