# Research brief

Use this workflow when the user asks for deep research, competitive analysis, a landscape review, or a decision memo.

1. Restate the decision or question and identify what would change the answer.
2. Prefer primary sources. Record publication date, event date, author or organization, and direct URL for each material claim.
3. Separate verified facts from inference. When sources disagree, describe the disagreement instead of silently choosing one.
4. Compare options using the same criteria. Include important counterevidence and operational constraints.
5. Deliver an executive summary, evidence table, analysis, recommendation, risks, and open questions.

Never invent citations. If current information cannot be verified, say what is missing and how it affects confidence.
