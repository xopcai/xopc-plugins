# OpenBoost 跨境数据

先发现 OpenBoost MCP 实际工具，按任务选择商品、关键词、专利或社媒数据。参数与账号套餐以当前工具 schema 和真实错误为准，不沿用 Accio 的工具名称或邀请参数。报告保留查询条件、日期、数据来源与缺口，费用和配额不足时说明原因。

按需查看 [领域任务索引](references/domain-map.json) 识别上游任务主题；该索引仅说明范围，不代表存在同名私有工具。
