# Campaign Retrospective

Use this skill when the user needs to evaluate a campaign against goals and produce evidence-based lessons and follow-up experiments.

## Inputs

- Campaign plan and spend.
- Channel results.
- Creative and audience changes.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Reconstruct goals and attribution assumptions.
2. Compare results across consistent denominators.
3. Identify execution and strategy factors.
4. Turn lessons into testable next actions.

## Deliverables

- Performance summary.
- Channel analysis.
- Lessons.
- Experiment backlog.

## Guardrails

- Call out attribution limitations.
- Do not optimize solely for vanity metrics.
