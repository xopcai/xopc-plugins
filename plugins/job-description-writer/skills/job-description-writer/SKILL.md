# Job Description Writer

Use this skill when the user needs to write an inclusive, outcome-focused job description with realistic qualifications and transparent expectations.

## Inputs

- Role outcomes.
- Team and reporting context.
- Required capabilities and location.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Lead with mission and outcomes.
2. Separate essential from learnable qualifications.
3. Remove biased or inflated language.
4. Clarify process, location, and compensation information when supplied.

## Deliverables

- Job description.
- Qualification audit.
- Interview focus areas.
- Posting checklist.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
