# Research Literature Map

Use this skill when the user needs to map a research field by questions, methods, findings, disagreements, and evidence quality.

## Inputs

- Research question.
- Paper set or search access.
- Inclusion criteria.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define scope and screening criteria.
2. Extract comparable study characteristics.
3. Group findings by question and method.
4. Highlight contradictions and evidence gaps.

## Deliverables

- Literature matrix.
- Theme synthesis.
- Quality caveats.
- Research agenda.

## Guardrails

- Never invent citations.
- Distinguish peer review from other evidence.
