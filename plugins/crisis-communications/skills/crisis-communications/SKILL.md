# Crisis Communications

Use this skill when the user needs to prepare accurate crisis communications with audience mapping, approvals, update cadence, and rumor control.

## Inputs

- Verified incident facts.
- Affected audiences.
- Legal, operational, and channel constraints.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Establish a verified fact base.
2. Map audience information needs.
3. Draft holding and update messages.
4. Define approval, monitoring, and correction workflow.

## Deliverables

- Holding statement.
- Audience messages.
- Q&A.
- Update operating plan.

## Guardrails

- Never speculate or conceal known material impact.
