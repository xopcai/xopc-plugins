# Stakeholder Update

Use this skill when the user needs to write a clear stakeholder update centered on outcomes, changes, risks, and decisions needed.

## Inputs

- Previous commitment.
- Current status and evidence.
- Audience and decisions needed.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Lead with what changed.
2. Explain impact on goals and dates.
3. Surface risks with mitigations.
4. Make asks explicit and time-bound.

## Deliverables

- Status summary.
- Progress and evidence.
- Risks.
- Decisions and asks.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
