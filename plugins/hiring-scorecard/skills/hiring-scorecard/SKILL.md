# Hiring Scorecard

Use this skill when the user needs to create a structured hiring scorecard tied to job outcomes and observable evidence.

## Inputs

- Role outcomes.
- Seniority and context.
- Interview stages.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define six-month and twelve-month outcomes.
2. Translate outcomes into observable competencies.
3. Assign each competency to an interview stage.
4. Create anchored scoring guidance.

## Deliverables

- Outcome profile.
- Competency rubric.
- Interview plan.
- Scoring template.

## Guardrails

- Avoid protected-class proxies.
- Score evidence, not interviewer affinity.
