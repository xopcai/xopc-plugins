# Interview Debrief

Use this skill when the user needs to run a structured interview debrief that weighs independent evidence against the role scorecard.

## Inputs

- Scorecard.
- Independent interviewer notes.
- Candidate work evidence.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Collect independent ratings before discussion.
2. Map evidence to competencies.
3. Resolve contradictions through evidence.
4. Record decision, risks, and reference questions.

## Deliverables

- Evidence matrix.
- Debrief agenda.
- Decision record.
- Follow-up questions.

## Guardrails

- Exclude protected attributes and affinity judgments.
