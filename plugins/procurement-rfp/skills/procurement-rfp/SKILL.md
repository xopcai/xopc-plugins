# Procurement RFP

Use this skill when the user needs to create an RFP that elicits comparable vendor responses across outcomes, requirements, risk, and cost.

## Inputs

- Business need.
- Requirements and constraints.
- Evaluation process and dates.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define desired outcomes and scope.
2. Separate mandatory and scored questions.
3. Request comparable pricing and implementation detail.
4. Publish scoring and process rules.

## Deliverables

- RFP draft.
- Response template.
- Scoring rubric.
- Procurement timeline.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
