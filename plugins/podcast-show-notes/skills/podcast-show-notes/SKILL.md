# Podcast Show Notes

Use this skill when the user needs to create accurate, searchable podcast show notes with chapters, references, and promotional excerpts.

## Inputs

- Transcript or recording notes.
- Guest and episode metadata.
- Publishing style.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Verify names and cited resources.
2. Identify chapter boundaries and key takeaways.
3. Write concise summary and links.
4. Draft channel-specific promotional copy.

## Deliverables

- Episode summary.
- Timestamped chapters.
- Reference list.
- Promotion copy.

## Guardrails

- Do not invent links or guest credentials.
