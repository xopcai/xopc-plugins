# Competitor Analysis

Use this skill when the user needs to compare competitors consistently and produce an evidence-backed positioning recommendation.

## Inputs

- Decision to support.
- Competitor set.
- Evaluation criteria and sources.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define a common comparison rubric before researching.
2. Prefer first-party pricing, documentation, and policy sources.
3. Separate observed capabilities from inferred strategy.
4. Score only when evidence supports comparable scoring.

## Deliverables

- Landscape summary.
- Comparison matrix.
- Positioning gaps.
- Recommended next moves.

## Guardrails

- Timestamp volatile facts.
- Never invent pricing or market-share data.
