# Organization Design

Use this skill when the user needs to evaluate an organization design against strategy, decision flow, accountability, capacity, and coordination cost.

## Inputs

- Strategy and work portfolio.
- Current structure and headcount.
- Decision and coordination pain points.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Map critical capabilities and value streams.
2. Identify decision bottlenecks and duplicated ownership.
3. Compare structural options.
4. Plan transition risks and operating mechanisms.

## Deliverables

- Design principles.
- Option comparison.
- Target operating model.
- Transition plan.

## Guardrails

- Do not make individual employment decisions.
