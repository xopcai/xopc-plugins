# Content Calendar

Use this skill when the user needs to build a sustainable content calendar aligned to audience needs, campaigns, channels, and production capacity.

## Inputs

- Audience and channels.
- Themes and campaigns.
- Capacity, dates, and goals.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define content pillars and funnel roles.
2. Balance formats and audience stages.
3. Sequence production and approvals.
4. Assign measurable objectives to each item.

## Deliverables

- Calendar.
- Content briefs.
- Ownership plan.
- Measurement plan.

## Guardrails

- Respect channel-specific constraints.
- Do not overload unconfirmed capacity.
