# Notion Workspace

Search and work with Notion content through Notion’s official remote MCP server.

## Install

```bash
xopc extensions install store:notion-workspace
```

The plugin installs disabled so its declared capabilities can be reviewed before enabling. On first use, XOPC opens the provider OAuth flow and completes setup after authorization.

## Included capability

- Skill: `notion-workspace`
- Remote MCP: `notion` at `https://mcp.notion.com/mcp`
