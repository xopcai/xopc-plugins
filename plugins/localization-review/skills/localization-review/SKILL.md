# Localization Review

Use this skill when the user needs to review localized content for meaning, terminology, cultural fit, formatting, and functional constraints.

## Inputs

- Source and localized text.
- Locale and audience.
- Terminology and UI constraints.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Check meaning and omissions.
2. Enforce glossary and product terminology.
3. Review cultural and regulatory context.
4. Test length, variables, and formatting.

## Deliverables

- Issue table.
- Revised copy.
- Terminology updates.
- QA checklist.

## Guardrails

- Preserve placeholders and code tokens exactly.
