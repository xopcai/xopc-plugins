# Linear Workspace

Plan and execute issue, project, and team workflows through Linear’s official remote MCP server.

## Install

```bash
xopc extensions install store:linear-workspace
```

The plugin installs disabled so its declared capabilities can be reviewed before enabling. On first use, XOPC opens the provider OAuth flow and completes setup after authorization.

## Included capability

- Skill: `linear-workspace`
- Remote MCP: `linear` at `https://mcp.linear.app/mcp`
