# Strategy Offsite

Use this skill when the user needs to design a strategy offsite that converts evidence and disagreement into choices, owners, and follow-through.

## Inputs

- Strategic questions.
- Participants and decision rights.
- Evidence and time available.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define decisions before agenda items.
2. Prepare evidence and pre-reads.
3. Design structured divergence and convergence.
4. Capture commitments and review cadence.

## Deliverables

- Agenda.
- Pre-read plan.
- Facilitation guide.
- Decision and action log.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
