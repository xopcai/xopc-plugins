# Service Blueprint

Use this skill when the user needs to map a service across customer actions, frontstage, backstage, systems, evidence, and failure points.

## Inputs

- Customer journey.
- Teams and systems.
- Known pain points and service goals.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define journey scope and actors.
2. Map customer and employee actions.
3. Connect dependencies, handoffs, and evidence.
4. Identify failure modes and redesign opportunities.

## Deliverables

- Service blueprint.
- Failure-point register.
- Opportunity backlog.
- Measurement plan.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
