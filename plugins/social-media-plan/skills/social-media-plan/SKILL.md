# Social Media Plan

Use this skill when the user needs to create a channel-specific social plan with audience value, production rhythm, and measurable learning.

## Inputs

- Audience and channels.
- Brand goals and voice.
- Campaigns and production capacity.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define each channel’s role.
2. Build repeatable content series.
3. Balance reach, trust, and conversion goals.
4. Design measurement and iteration cadence.

## Deliverables

- Channel strategy.
- Publishing calendar.
- Post briefs.
- Measurement plan.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
