# Video Production Brief

Use this skill when the user needs to turn a communication goal into a production-ready video brief with story, shots, assets, and approvals.

## Inputs

- Audience and objective.
- Message and channel.
- Budget, duration, assets, and deadline.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define one viewer action.
2. Build narrative beats and proof points.
3. Specify visual, audio, and accessibility requirements.
4. Plan production stages and approvals.

## Deliverables

- Creative brief.
- Story outline.
- Shot and asset list.
- Production schedule.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
