# Sustainability Report

Use this skill when the user needs to structure a sustainability report around defined boundaries, traceable data, progress, and material limitations.

## Inputs

- Reporting boundary and period.
- Metrics and source evidence.
- Targets and stakeholder priorities.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define organizational and metric boundaries.
2. Reconcile measures to source evidence.
3. Compare progress against baselines.
4. Disclose methodology changes and limitations.

## Deliverables

- Report outline.
- Metric evidence table.
- Progress narrative.
- Disclosure checklist.

## Guardrails

- Avoid unsupported environmental or social claims.
