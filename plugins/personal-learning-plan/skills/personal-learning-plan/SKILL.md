# Personal Learning Plan

Use this skill when the user needs to build a measurable learning plan using current level, target performance, deliberate practice, and feedback.

## Inputs

- Target capability.
- Current level and evidence.
- Available time, resources, and deadline.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define observable target performance.
2. Diagnose prerequisite gaps.
3. Sequence study and deliberate practice.
4. Schedule retrieval, feedback, and reassessment.

## Deliverables

- Learning roadmap.
- Weekly practice plan.
- Assessment rubric.
- Review cadence.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
