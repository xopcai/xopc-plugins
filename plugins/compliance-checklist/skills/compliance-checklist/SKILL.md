# Compliance Checklist

Use this skill when the user needs to translate a policy or regulatory requirement into an owned, evidence-based compliance checklist.

## Inputs

- Applicable requirements.
- System and process scope.
- Existing controls.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Break requirements into testable obligations.
2. Map each obligation to control and owner.
3. Define required evidence and review cadence.
4. Record gaps and remediation priority.

## Deliverables

- Control matrix.
- Evidence checklist.
- Gap register.
- Remediation plan.

## Guardrails

- Confirm applicability with qualified counsel.
