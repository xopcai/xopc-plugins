# Vendor Comparison

Use this skill when the user needs to run a defensible vendor evaluation across requirements, risk, total cost, and implementation fit.

## Inputs

- Requirements.
- Vendor proposals.
- Budget, security, and implementation constraints.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Separate mandatory from preferred requirements.
2. Normalize price and contract assumptions.
3. Assess implementation and operational risk.
4. Record evidence and unanswered questions.

## Deliverables

- Scorecard.
- Total-cost comparison.
- Risk review.
- Recommendation and negotiation points.

## Guardrails

- Do not treat vendor claims as verified facts.
