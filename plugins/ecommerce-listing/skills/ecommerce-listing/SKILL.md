# E-commerce Listing

Use this skill when the user needs to create accurate, channel-ready product listings from verified product facts and audience needs.

## Inputs

- Product specifications.
- Target customer.
- Channel rules and brand voice.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Identify customer problem and differentiators.
2. Map verified features to benefits.
3. Structure title, bullets, description, and metadata.
4. Check prohibited and unsupported claims.

## Deliverables

- Listing copy.
- Attribute table.
- Image brief.
- Compliance checklist.

## Guardrails

- Never invent specifications, certifications, or outcomes.
