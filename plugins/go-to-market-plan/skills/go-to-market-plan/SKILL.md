# Go-to-Market Plan

Use this skill when the user needs to build a coordinated go-to-market plan covering audience, positioning, channels, enablement, and measurement.

## Inputs

- Offer and launch scope.
- Target segments.
- Market evidence, budget, and timeline.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define target segment and job-to-be-done.
2. Develop positioning and proof points.
3. Sequence channel, sales, and customer-success motions.
4. Define readiness gates and leading indicators.

## Deliverables

- Positioning.
- Launch plan.
- Enablement checklist.
- Measurement dashboard.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
