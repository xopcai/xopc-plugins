# Qualitative Coding

Use this skill when the user needs to create and apply a transparent qualitative coding framework with evidence, disagreement, and iteration.

## Inputs

- Text corpus.
- Research questions.
- Sampling context.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Develop initial codes from questions and data.
2. Define inclusion and exclusion examples.
3. Apply codes consistently and note ambiguity.
4. Synthesize patterns and counterexamples.

## Deliverables

- Codebook.
- Coded evidence table.
- Theme synthesis.
- Reliability notes.

## Guardrails

- Protect participant identity.
- Do not turn qualitative counts into prevalence claims.
