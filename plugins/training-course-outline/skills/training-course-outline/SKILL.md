# Training Course Outline

Use this skill when the user needs to design an outcome-based course with assessments, practice, sequencing, and accessibility considerations.

## Inputs

- Learners and prerequisites.
- Target capabilities.
- Duration and delivery constraints.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Write observable learning outcomes.
2. Sequence concepts from prerequisite to application.
3. Design authentic practice and assessment.
4. Plan feedback and accessibility.

## Deliverables

- Course map.
- Lesson outlines.
- Assessment plan.
- Facilitator checklist.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
