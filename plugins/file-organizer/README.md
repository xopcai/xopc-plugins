# 文件整理助手

无需账号。安装后选择一个本地文件夹，在对话中说明要整理的文件。插件先显示按类型或修改月份分类的预览，确认后才移动，不覆盖文件，并可按操作记录撤销。

示例：「预览把这个文件夹中的 PDF 和表格分类，先不要移动。」

只处理显式选择的文件，不扫描全盘、不跟随符号链接、不自动删除重复文件。每次最多 100 个文件，单个文件最大 100 MiB，移动目标必须在同一文件系统。撤销保留空文件夹；有新文件或修改冲突时停止，避免覆盖。卸载时保留插件数据才能继续使用历史撤销记录。异常退出遗留锁需在确认原进程已退出并备份日志后处理，不自动按时间强行解锁。

所有程序包含在 Store 包内，无额外运行时下载。Apache-2.0，XOPC 原创。
