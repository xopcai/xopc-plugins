# Sales Account Plan

Use this skill when the user needs to develop an evidence-based account plan with stakeholder map, value hypothesis, risks, and next actions.

## Inputs

- Account context.
- Known stakeholders.
- Opportunity history and product fit.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Map business priorities and change events.
2. Identify stakeholders and missing relationships.
3. Form a value hypothesis tied to evidence.
4. Sequence discovery and mutual action steps.

## Deliverables

- Account brief.
- Stakeholder map.
- Value hypothesis.
- Mutual action plan.

## Guardrails

- Do not invent stakeholder motives or internal information.
