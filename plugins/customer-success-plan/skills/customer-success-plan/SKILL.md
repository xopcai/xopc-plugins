# Customer Success Plan

Use this skill when the user needs to create a mutual success plan connecting customer outcomes, adoption signals, milestones, and risks.

## Inputs

- Customer goals.
- Product usage and stakeholders.
- Contract milestones and risks.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Translate goals into measurable outcomes.
2. Map capabilities and adoption milestones.
3. Assign mutual owners and checkpoints.
4. Define risk signals and intervention plays.

## Deliverables

- Success plan.
- Milestone roadmap.
- Stakeholder map.
- Risk playbook.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
