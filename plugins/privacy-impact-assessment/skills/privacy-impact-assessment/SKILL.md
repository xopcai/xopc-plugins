# Privacy Impact Assessment

Use this skill when the user needs to assess personal-data processing, necessity, user impact, controls, retention, and open legal questions.

## Inputs

- Data-flow description.
- Data categories and subjects.
- Purpose, retention, and sharing.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Map collection through deletion.
2. Evaluate necessity and proportionality.
3. Identify legal-basis and notice questions.
4. Recommend minimization and control measures.

## Deliverables

- Data map.
- Risk assessment.
- Control plan.
- Questions for counsel.

## Guardrails

- Do not provide legal conclusions.
- Minimize personal data in the assessment.
