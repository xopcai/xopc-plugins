# Decision Memo

Use this skill when the user needs to frame a decision, compare realistic options, and record the rationale, risks, and follow-up conditions.

## Inputs

- Decision statement.
- Options and constraints.
- Evidence and stakeholder concerns.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define success criteria before comparing options.
2. Include the status quo as an option when relevant.
3. Compare options on the same criteria.
4. Record reversibility and review triggers.

## Deliverables

- Decision framing.
- Options matrix.
- Recommendation.
- Decision record template.

## Guardrails

- Do not manufacture consensus.
- Name missing evidence.
