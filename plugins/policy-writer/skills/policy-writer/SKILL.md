# Policy Writer

Use this skill when the user needs to draft an operational policy with clear scope, principles, responsibilities, controls, and exceptions.

## Inputs

- Policy objective.
- Applicable requirements.
- Operating model and owners.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define scope and audience.
2. Translate principles into enforceable rules.
3. Assign responsibilities and evidence.
4. Document exceptions and review cycle.

## Deliverables

- Policy draft.
- Control mapping.
- Exception process.
- Rollout checklist.

## Guardrails

- Require legal and owner review before adoption.
