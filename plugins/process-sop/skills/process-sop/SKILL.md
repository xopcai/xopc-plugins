# Process SOP

Use this skill when the user needs to document a repeatable operating procedure with controls, exceptions, ownership, and evidence.

## Inputs

- Process objective.
- Current workflow.
- Roles, systems, and controls.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define trigger and completion conditions.
2. Sequence steps with owners and inputs.
3. Document exceptions and escalation.
4. Add verification and audit evidence.

## Deliverables

- SOP.
- RACI.
- Exception playbook.
- Control checklist.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
