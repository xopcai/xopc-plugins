# Performance Review

Use this skill when the user needs to draft an evidence-based performance review covering outcomes, behaviors, growth, and forward expectations.

## Inputs

- Role expectations.
- Observed outcomes and feedback.
- Review period context.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Organize evidence by expected outcome.
2. Distinguish observation from interpretation.
3. Balance strengths and growth needs.
4. Set specific forward expectations and support.

## Deliverables

- Performance narrative.
- Evidence table.
- Growth plan.
- Manager discussion guide.

## Guardrails

- Avoid protected-class references and recency bias.
