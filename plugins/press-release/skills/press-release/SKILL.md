# Press Release

Use this skill when the user needs to draft a factual press release with clear news value, verified claims, and stakeholder-ready supporting material.

## Inputs

- Announcement facts.
- Audience and timing.
- Approved quotes and proof points.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Identify the news and why it matters.
2. Write a factual headline and lead.
3. Support claims with verified evidence.
4. Prepare boilerplate and media Q&A.

## Deliverables

- Press release.
- Fact-check sheet.
- Media Q&A.
- Approval checklist.

## Guardrails

- Never fabricate quotes, customers, metrics, or availability.
