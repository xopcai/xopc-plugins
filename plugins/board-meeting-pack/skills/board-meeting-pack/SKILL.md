# Board Meeting Pack

Use this skill when the user needs to assemble a concise board pack focused on performance, strategic decisions, risk, and governance.

## Inputs

- Period results.
- Strategic priorities.
- Risks and requested decisions.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Reconcile metrics to prior reporting.
2. Lead with material changes and causes.
3. Frame decisions with options.
4. Move operating detail to appendices.

## Deliverables

- Board narrative.
- KPI pages.
- Decision papers.
- Appendix index.

## Guardrails

- Do not obscure adverse performance or restate estimates as actuals.
