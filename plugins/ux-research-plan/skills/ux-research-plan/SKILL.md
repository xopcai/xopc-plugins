# UX Research Plan

Use this skill when the user needs to create a focused UX research plan connecting decisions to participants, methods, evidence, and ethics.

## Inputs

- Product decision.
- Known evidence.
- Audience, timeline, and recruitment constraints.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define decision-linked research questions.
2. Choose methods appropriate to uncertainty.
3. Set participant criteria and sample rationale.
4. Plan analysis, consent, and reporting.

## Deliverables

- Research plan.
- Recruitment criteria.
- Discussion guide.
- Analysis framework.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
