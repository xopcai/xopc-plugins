# Accessibility Review

Use this skill when the user needs to review a digital experience for accessible structure, interaction, content, and testing coverage.

## Inputs

- Interface or specification.
- Supported platforms.
- Accessibility target.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Trace keyboard and assistive-technology journeys.
2. Review semantics, focus, contrast, motion, and errors.
3. Prioritize barriers by user impact.
4. Define manual and automated verification.

## Deliverables

- Findings.
- Remediation guidance.
- Test plan.
- Residual-risk notes.

## Guardrails

- Do not claim conformance without appropriate testing.
