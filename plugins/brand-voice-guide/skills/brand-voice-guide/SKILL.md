# Brand Voice Guide

Use this skill when the user needs to create an actionable brand voice guide with principles, examples, boundaries, and channel adaptations.

## Inputs

- Brand positioning.
- Audience.
- Representative good and bad examples.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Identify consistent voice attributes.
2. Translate attributes into observable writing choices.
3. Define tone shifts by context.
4. Provide before-and-after examples.

## Deliverables

- Voice principles.
- Style rules.
- Channel adaptations.
- Example library.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
