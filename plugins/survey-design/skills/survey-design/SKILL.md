# Survey Design

Use this skill when the user needs to design a survey that connects research questions to unbiased items, sampling, and analysis.

## Inputs

- Research objectives.
- Target population.
- Delivery and analysis constraints.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Map each question to a decision.
2. Choose appropriate response scales.
3. Remove leading, double-barreled, and ambiguous wording.
4. Plan sampling, pilot, and analysis.

## Deliverables

- Survey instrument.
- Question rationale.
- Pilot checklist.
- Analysis plan.

## Guardrails

- Collect only necessary personal data.
