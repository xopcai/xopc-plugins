# Promotion Plan

Use this skill when the user needs to design an e-commerce promotion with economics, inventory constraints, channel execution, and measurement.

## Inputs

- Commercial objective.
- Products and margins.
- Audience, channels, and inventory.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define target behavior and offer mechanics.
2. Model unit economics and break-even.
3. Check inventory and operational constraints.
4. Design holdout or comparison measurement.

## Deliverables

- Offer design.
- Economics table.
- Execution calendar.
- Measurement plan.

## Guardrails

- State material assumptions and missing evidence.
- Ask before taking external or irreversible action.
