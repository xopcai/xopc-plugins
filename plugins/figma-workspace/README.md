# Figma Workspace

Inspect Figma design context and support design-to-implementation workflows through Figma’s official remote MCP server.

## Install

```bash
xopc extensions install store:figma-workspace
```

The plugin installs disabled so its declared capabilities can be reviewed before enabling. On first use, XOPC opens the provider OAuth flow and completes setup after authorization.

## Included capability

- Skill: `figma-workspace`
- Remote MCP: `figma` at `https://mcp.figma.com/mcp`
