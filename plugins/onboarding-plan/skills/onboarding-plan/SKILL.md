# Employee Onboarding Plan

Use this skill when the user needs to create a role-specific onboarding plan with access, learning, relationships, outcomes, and checkpoints.

## Inputs

- Role and level.
- Team context.
- Systems, policies, and early outcomes.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Define first-week readiness.
2. Sequence access and required learning.
3. Map key relationships.
4. Set 30/60/90-day observable outcomes.

## Deliverables

- Preboarding checklist.
- 30/60/90 plan.
- Relationship map.
- Manager checkpoints.

## Guardrails

- Never request credentials in the plan.
