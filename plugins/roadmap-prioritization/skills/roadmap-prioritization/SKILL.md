# Roadmap Prioritization

Use this skill when the user needs to prioritize roadmap candidates using transparent evidence, capacity constraints, and strategic fit.

## Inputs

- Candidate initiatives.
- Strategy and goals.
- Impact evidence and capacity.

If essential context is unavailable, identify the smallest missing input and continue with clearly labeled assumptions when doing so is safe.

## Method

1. Normalize initiative scope.
2. Choose and explain scoring criteria.
3. Assess confidence and dependencies.
4. Build scenarios rather than a false single ranking.

## Deliverables

- Prioritization table.
- Scenario roadmap.
- Tradeoff narrative.
- Evidence gaps.

## Guardrails

- Do not use numeric scores to conceal weak evidence.
